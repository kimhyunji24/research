# 프로브 강화 점검 계획 (2026-10-20, 결과 보기 전 기록, 탐색)

논문 4.7절용. "프로브가 약해서 baseline을 못 넘었다"는 반론을 점검한다. 확증 근거로 쓰지 않는다. 1회 실행한다.

## 데이터·설정 (기존과 같음)
- Qwen2.5-3B, `data/main_3b` 앞 250게임, 과제 단위, step 0·1·2, 3B 자기 hidden.
- 장면 단위 층화 5-fold × 2(seed 0·1), 하이퍼파라미터는 학습 fold 안 장면 단위 3-fold로 고름(nested), 장면 cluster bootstrap 1,000회(seed 0). 순열 검정은 하지 않는다(계산량, CI로 판단).

## 변형 (모두 표준화 포함, 학습 fold 안에서만 적합)
| 이름 | 내용 |
|---|---|
| base | 75% 깊이, linear, C ∈ {10⁻⁴…1}(기존 설정, 기준점) |
| wideC | 75% 깊이, linear, C ∈ {10⁻⁶, 10⁻⁵, …, 10², 10³}(10개) |
| pca | 75% 깊이, PCA k ∈ {8, 32, 64, 128}와 C(기존 5개)를 함께 nested로 고름 |
| concat | 네 깊이(25/50/75/100%)를 이어 붙인 8,192차원, linear, 기존 C |
| mlp | 75% 깊이, 은닉 1층 MLP, (은닉 32·128) × (α 10⁻³·10⁻¹) 4개를 nested로 고름, early stopping |
| r5+hid | 5단 baseline 입력(수치 + TF-IDF)에 75% hidden을 더한 하나의 로지스틱(기존 C) |

## 비교 (탐색)
1. 각 변형 − 5단 (base, wideC, pca, concat, mlp; step 0–2, 15개)
2. r5+hid − 5단 (3개): hidden이 5단 위에 정보를 더하는가
- 판정 표기는 기존 규칙(우수 = CI 하한 > 0)을 쓰되, 18개 비교에 보정 없이 탐색으로만 보고하고, 참고로 Holm 보정 p(bootstrap 양측)를 함께 적는다.

## 미리 정한 해석
- 어느 변형도 5단보다 우수하지 않고 r5+hid도 5단보다 우수하지 않으면: "프로브를 강화해도 결론은 바뀌지 않는다"를 시사.
- 어떤 변형이 우수하면: 그 변형만 탐색 결과로 보고하고, 확증하려면 새 데이터와 새 사전 기록이 필요하다고 적는다(이번에는 하지 않는다).

## 한계 (미리)
- 앞 250게임은 이미 여러 탐색에 썼다. 비교가 많아 우연히 우수가 하나 나올 수 있다.
- 비선형 프로브는 작은 격자만 본다.
